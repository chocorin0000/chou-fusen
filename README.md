# 超！付箋電卓 Web 版

計算した数字を付箋にして貼っておき、あとで足したり使ったりできる電卓です（広告なし）。Android 版と同じ動きです。

- 開く: https://chocorin0000.github.io/chou-fusen/
- iPhone・iPad は Safari で開いて、共有ボタン →「ホーム画面に追加」すると、アプリのように画面いっぱいで使えます。
- 付箋や履歴は、そのブラウザの中（localStorage）に保存されます。
- 消費税（10%・8%）、円・ドル・ユーロ（レートは open.er-api.com）。
